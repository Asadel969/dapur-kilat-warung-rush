**Dapur Kilat — Warung Rush** is a fast-paced cooking game set in an Indonesian street-food stall. Orders pile up on the board, and you are the whole kitchen: tap an order ticket, toss its three ingredients into a pan, wait for it to cook on the stove, then tap the finished plate on the serving shelf before the customer's patience runs out. A 100-second shift, three hearts, four dishes on the menu (Nasi Goreng, Mie Ayam, Soto Ayam, Ayam Geprek), and a combo bonus for serving dish after dish without losing a customer. Wrong ingredient in the pan? It is ruined — dump it and start over. All art is drawn in code on a canvas, all sound is synthesized in the browser; the game plays fully offline in a desktop browser, with mouse and keyboard.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
